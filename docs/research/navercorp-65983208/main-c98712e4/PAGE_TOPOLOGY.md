# NAVER main page topology

1. Fixed site header: logo, desktop navigation, language selector and search; compact mobile menu below the 767px breakpoint.
2. Main headline: Korea/Seoul clock, stock summary, four-slide visual headline carousel, and three supporting cards.
3. News masonry: `We the Navigators` title with a three-column card layout on desktop, two columns at tablet, and a vertical feed on mobile.
4. Middle promotion: five content slides with background-color transitions and a four-second autoplay controller.
5. Technology summary: three horizontally expanding panels. The first panel is open initially; click or keyboard activation changes the active panel.
6. Partner support: two ARIA tabs for partner and developer links.
7. Footer: animated brand mark, link groups, social links, legal links, and mobile collapsible link groups.

The desktop header is fixed and changes class after scrolling. The public page is content-only; CMS/admin routes are intentionally deferred.
